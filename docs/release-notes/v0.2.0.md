**Analogizer support.** Time Pilot now works with RndMnkIII's
[Analogizer](https://github.com/RndMnkIII/Analogizer) adapter: the board's
own picture on a CRT, and native controllers through SNAC. Confirmed on a
Pocket with an Analogizer and a CRT.

### What's new

- **Video out of the adapter's VGA port**: RGBS, RGsB, YPbPr, Y/C (NTSC or
  PAL), or scandoubled for a VGA monitor. The signal is the board's own:
  256×224 at 16.0 kHz, 60.6 Hz.
- **Set up from the core's own menu**, no `analogizer.bin` file needed:
  **Analogizer** (Off, On, or "On, Pocket off" for the CRT only),
  **Analogizer Video**, **SNAC Adapter**, **SNAC Assignment**. Off by
  default; with it off the core plays exactly as before.
- **H / V Position** centre the picture on the CRT (24 pixels left to 8
  right, 16 lines up to 4 down).
- **H Size** sets the picture's width, -20% to +20%. With the set on its
  side that is the game's *height*. The board leaves little room before
  hsync, so first centre the picture with H Position (about -24), then
  widen it. Where the two together would reach the sync, the core trims the
  picture's edge instead, so the set never loses sync.
- **SNAC controllers** (DB15, NES, SNES, PC Engine, PlayStation): any pad
  plays whichever turn is up, upright or cocktail.

### Before you install

The CRT gets the vertical monitor's own picture, unrotated: **stand the set
on its side, turned clockwise as you face it** (top of the set to the
right), as the cabinet's was.

**With this core the Pocket powers the cartridge slot.** Take any game
cartridge out first. Set the adapter up as its
[How to use it](https://github.com/RndMnkIII/Analogizer/wiki/How-to-use-it%3F)
page says (SNAC switch on A, 5 V into its USB-C port, the audio cable into
the Pocket's headphone socket).

### Installing

Unzip onto the Pocket SD card root, overwriting previous files. The ROM
image goes in `Assets/timeplt/common/` (build it from your own MAME romset
with the included `mra_build.py`).
